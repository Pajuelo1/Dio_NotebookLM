# Dio_NotebookLM

# 📊 Caderno Temático — Educação Financeira Pessoal: Orçamento e Reserva de Emergência

> Desafio de Projeto (DIO): explorando o NotebookLM como ferramenta de aprendizagem ativa

## 🎯 Contexto e Objetivos

Este repositório documenta a construção de um **caderno temático no NotebookLM** sobre **educação financeira pessoal**, com foco em dois pilares centrais: **orçamento pessoal** e **reserva de emergência**.

Escolhi esse tema porque é uma base prática para qualquer decisão financeira futura (investimentos, crédito, planejamento de longo prazo) e porque domínio financeiro básico é uma competência cada vez mais relevante também para profissionais de tecnologia que lidam com gestão de projetos, contratos e carreira.

**Objetivos de estudo:**
- Entender os princípios de um orçamento pessoal funcional (receitas, despesas fixas/variáveis, metas).
- Compreender o conceito, o dimensionamento e a alocação de uma reserva de emergência.
- Identificar erros comuns que levam ao endividamento e como evitá-los.
- Praticar engenharia de prompts para extrair, comparar e validar informações financeiras com apoio de IA.
- Consolidar o aprendizado em um miniguia reutilizável para revisões futuras.

## 🧠 Engenharia de Prompts e "Cicatrizes"

1. Quais são os componentes essenciais de um orçamento pessoal eficaz segundo as fontes?
2. Como calcular o tamanho ideal de uma reserva de emergência e onde ela deve ser alocada?
3. Quais os erros mais comuns que levam pessoas ao endividamento, segundo os cadernos do Banco Central?
4. Existe consenso entre as fontes sobre o método de controle de gastos (ex: regra 50-30-20)? Onde elas divergem?
5. Como as instituições financeiras brasileiras têm atuado na promoção da educação financeira?
